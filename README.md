Entry for the [Monday Morning Punchlines](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty on [make.fun](https://make.fun) (referral `4fxhr3y1`).

## The joke

> Monday morning is the only time my bed and my boss both want me, and somehow I'm disappointing both.

100 characters. The whole Monday conflict in one line: your bed won't let go,
your boss wants you at nine, and somehow you're letting both of them down at
once.

## How it works

`main.py` writes exactly that one line (no trailing newline) to
`entry.txt` inside the output directory — `$MAKEFUN_OUTPUT_DIR` when set,
otherwise `/output`.

## Run

```sh
python3 main.py
# writes entry.txt to /output, or to $MAKEFUN_OUTPUT_DIR when set
```
